Host site

This page stands in for a client's website. The widget below is loaded with a single <script> tag, same as it would be on a real site — replace data-key with a tenant's real public_widget_key (seed one via pnpm seed-demo-salon and check the tenants table, or create one via /admin).

You can also drive it programmatically via window.AIReceptionist.

Schedule widget

An inline widget mounts into any <div data-chatalot="schedule"> on the page; add data-mode="float" to show it as a launcher bubble instead. Add data-chat="off" to the script tag to load booking widgets without the chat.

Appointment widget

Services first, then who, then when: <div data-chatalot="appointment">.
